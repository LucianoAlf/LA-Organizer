🚨 Fix RLS crítico (regressão Sprints 0-2):
- Bug: policies "Service role full access" criadas com `FOR ALL TO public
  USING (true)`. Postgres trata `public` como qualquer role, incluindo
  authenticated → vazava TODAS as linhas para QUALQUER usuário logado.
- Encontrado em smoke test multiuser (Alf vs Anne): Alf (director)
  conseguia SELECT de tasks/events context='personal' da Anne.
- Fix: re-escopo `TO service_role` em todas as policies que matchavam o
  pattern. service_role bypassa RLS via BYPASSRLS attribute, policy é
  redundante mas garante que authenticated NÃO casa.
- Validação pós-fix: Alf sees only Anne's work events (1), 0 personal.
