# NIVEL DE ISOLAMENTO de cada bateria (laudo v2.6, bloqueador 10).
#
# A v2.6 chamava 166 asseracoes de "auto-contidas" e nao eram: uma apontava para o .env e a
# rede do runtime, outra criava arquivo no /run real. Rotulo errado e pior que rotulo nenhum,
# porque quem le para de conferir.
#
#   unit                  nao toca /run, .env, crontab, backup real, rede nem docker.
#                         So $TMPDIR e processos proprios.
#   integration-sandbox   sobe servidor local, docker ou binario falso; tudo em diretorio
#                         descartavel. Nao le nem escreve estado vivo.
#   environment-read-only SO LE o estado vivo (crontab, /run, repo de producao, .env, rede).
#                         Nunca escreve. E declarado, e a contagem sai separada.
#   environment-controlled-write-probe
#                         TENTA escrever em alvos de producao para provar que a permissao
#                         nega. Fora do total padrao; so roda sob gate explicito. Existe
#                         porque "read-only" com syscall de escrita e rotulo falso.
#
# Bateria sem nivel declarado REPROVA o runner: classificacao esquecida vira, com o tempo,
# um teste que toca producao sem ninguem notar.
#
# formato:  <arquivo>  <nivel>  <por que>

teste-seq-compare.sh            unit                   funcao pura de comparacao, sem I/O externo
teste-publicar.sh               unit                   publicacao atomica em diretorio temporario
teste-lock-dono.sh              unit                   lock em diretorio temporario; nenhum /run real

teste-deploy-lock-sha.sh        unit                   repo git descartavel; so le o .ps1 do pacote
teste-preflight-modo.sh         unit                   repo git descartavel com core.fileMode

teste-vercel-prova.sh           integration-sandbox     API e sites falsos em portas efemeras
teste-cron-canonico.sh          integration-sandbox     crontab falso no PATH; nunca o crontab real
teste-bootstrap.sh              integration-sandbox     repo git descartavel; bootstrap em dir proprio
teste-e2e-transicao.sh          integration-sandbox     transicao v2.5->candidato inteira em repo descartavel
